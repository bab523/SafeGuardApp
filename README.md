# SafeGuard – AI-Powered Personal Safety App

A cross-platform mobile safety app built with React Native and Expo, featuring an SOS emergency system, real-time GPS location sharing, and a rule-based scam detector.

## Features
- 🚨 SOS emergency alert with one tap
- 📍 Real-time GPS location sharing with trusted contacts
- 🛡️ Rule-based scam message checker
- 👥 Emergency contacts management
- 🔐 Login screen

## Tech Stack
- React Native (Expo)
- Node.js
- Expo EAS (Android build)
